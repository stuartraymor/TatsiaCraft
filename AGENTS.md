# Developer and agent instructions

Every completed revision must be uploaded to https://github.com/stuartraymor/TatsiaCraft and published as a GitHub release. Local changes or a local build alone do not complete a revision. Do not report a release as published until the remote commit, tag, release and assets have been verified. If authentication or networking blocks publication, report the blocker and preserve the local work.

Use `scripts/release.ps1 -Message "Describe the revision" -ToolsPath <compatible-tools-directory>` after staging the intended source changes. The script validates the build, media-bin multi-item drag/drop, atomic sequential media-bin batch insertion, bidirectional media-bin/timeline navigation, media-bin source preview/transport/failure/retry/disposal, organization/cleanup and Details, Favorites/Behaviors, atomic export commit lock recovery, audio points and range silencing, silence/restore audio, stitching, ripple insert, ripple delete/move and audio/video separation, timeline markers/chapters, reference-style menus/wording/tooltips/icons and shortcuts, multi-selection/group membership and unit movement, batch clipboard/undo/preview/export, project-save lock recovery and Save As state, anchored resize snapping, crop source movement, canvas alignment/snapping/guides, off-canvas display, anchored resize, pan, crop/preview/export and canvas tests, runs isolated installation tests, installs the version, verifies installed startup/shutdown, assigns the next revision, commits, pushes main and the version tag, and publishes the GitHub release with executable and source assets. Use `-PrepareOnly` to run checks and install without committing or publishing; smoke-test the installed workflow, then rerun the same command without `-PrepareOnly` and with the unchanged staged tree to publish the preserved executable. The installed and released executable hashes must match. Do not put credentials, local recordings, proprietary reference assets or generated dependency binaries in Git.

`VERSION` is the only version source. Minor and patch positions range from 0 through 12. Sequence: 0.0.0 → 0.0.1 → … → 0.0.12 → 0.1.0; 0.12.12 → 1.0.0. Each completed revision receives one new version; intermediate edits and test repairs belong to that same revision.

Display `TatsiaCraft <version>` in the top-left native title bar beside the application icon, including project open/save/dirty states. Home and About must use the same version. Preserve existing project formats, media and user data while revising the product.

The application is an independent development preview. Do not claim complete reference parity or comparative speed/quality improvements without supporting verification.
